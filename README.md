# Python Learning

Personal practice repo for refreshing Python fundamentals. Run any script from the repo root, e.g. `python practice/factorial.py` (use `python -m OOPS.Packages` for scripts that import other packages).

| Folder | Topic | Scripts |
|---|---|---|
| [Basics/](Basics/) | Loops, conditionals, lambdas | `conditonal_looping.py`, `lambda.py` |
| [OOPS/](OOPS/) | Classes, objects, importing packages | `Class_Object.py`, `Packages.py` |
| [practice/](practice/) | Small problems: factorial, Fibonacci, grading, odd/even, bubble sort, balance calculator, word count, word sort, set difference/intersection | 9 scripts |
| [DSA/](DSA/) | Data structures and algorithms | Not started |
